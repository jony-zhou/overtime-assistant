# 測試模式使用說明

## 概述

測試模式允許你在不登入、不連線的情況下查看應用程式的完整 UI 和功能，使用假數據進行操作。

## 啟動測試模式

### 方法 1: 使用命令列參數 `-t`

```bash
python app.py -t
```

### 方法 2: 使用命令列參數 `--test`

```bash
python app.py --test
```

## 測試模式特性

✅ **跳過登入**: 自動進入主畫面，不需要輸入帳號密碼
✅ **假數據**: 使用隨機生成的測試數據
✅ **不連線**: 完全不會對外連線，安全無風險
✅ **完整 UI**: 可以查看所有分頁和功能介面
✅ **視窗標題標記**: 視窗標題會顯示 `[測試模式]` 標記

## 測試模式包含的假數據

1. **出勤記錄** - 最近 30 天的工作日出勤數據
2. **個人記錄** - 20 筆已申請的加班記錄
3. **打卡記錄** - 30 天的打卡時間記錄
4. **統計數據** - 根據假數據計算的統計資訊

## 測試模式限制

⚠️ **申報功能已禁用**: 在測試模式下無法實際提交加班申請
⚠️ **資料不會儲存**: 所有操作都不會影響實際系統
⚠️ **每次啟動數據不同**: 假數據是隨機生成的

## 適用場景

- 🔍 **查看架構**: 了解應用程式的整體結構和 UI 設計
- 🎨 **UI 開發**: 進行介面調整和優化時測試效果
- 🐛 **問題排查**: 在不影響真實數據的情況下調試問題
- 📚 **功能展示**: 向他人展示系統功能時使用

## 開發者指南

### 假數據生成器位置

```
src/utils/mock_data.py
```

### 自訂假數據

你可以修改 `MockDataGenerator` 類別中的方法來調整假數據的生成邏輯：

- `generate_attendance_records(days)` - 出勤記錄
- `generate_personal_records(count)` - 個人記錄
- `generate_punch_records(days)` - 打卡記錄
- `generate_overtime_submissions(count)` - 申報記錄

### 測試假數據生成器

```bash
python test_mock_mode.py
```

## 切換回正常模式

不使用 `-t` 或 `--test` 參數即可：

```bash
python app.py
```

正常模式會顯示登入畫面，需要輸入有效的帳號密碼才能使用。
